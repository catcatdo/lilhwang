시놀로지 NAS DSM 7.0 Docker로 마인크래프트 서버 만들기

2026-02-24 기술 릴황

안녕하세요! 오늘은 시놀로지 나스로 마인크래프트 서버 직접 열어보는 글이야. DSM 7.0 기준으로 진행할 거고, Docker(신형 DSM에서는 Container Manager로 이름이 보일 수도 있어)로 구성할 거야. 그럼 시작핸보자.

먼저 준비물부터 체크 (대략 가격 포함)

내가 실제로 준비했던 기준으로 적어볼게. 가격은 2026년 2월 기준 대략값이라 판매처에 따라 달라질 수 있어.

  • 시놀로지 NAS 본체 (플러스 모델 권장): 약 45만~120만원
  • NAS용 HDD 2개 (예: 4TB x 2): 약 28만~40만원
  • 추가 RAM 8GB~16GB 권장: 약 4만~12만원
  • 기가비트 공유기: 약 5만~20만원
  • 마인크래프트 Java Edition 계정: 약 4만원대
  • 전기요금(24시간 구동 시): 월 약 5천원~1만5천원 수준(모델/요금제 따라 차이)

최소 구성으로 시작하면 약 80만원대도 가능하고, 여유 있게 구성하면 150만원 이상도 나와. 친구 3~5명 소규모 서버면 CPU보다 RAM 체감이 훨씬 큰 편이었어.

Step 1. DSM 7.0에서 Docker 패키지 설치

패키지 센터에서 Docker를 설치해줘. 만약 모델/DSM 버전에 따라 Container Manager로 보이면 그걸 설치하면 돼. 핵심은 컨테이너를 실행할 수 있으면 된다.

설치가 끝나면 공유 폴더를 하나 만들어서 서버 데이터를 보관하자. 예시 경로는 아래처럼:

/volume1/docker/minecraft

여기에 월드 데이터, 설정 파일이 저장되니까 나중에 백업/복구가 쉬워져.

Step 2. 마인크래프트 컨테이너 생성

초보면 UI(컨테이너 생성 마법사)로 해도 되고, 나는 재현이 쉬운 compose 방식을 추천해. 아래 예시로 시작하면 가장 안정적이었어.

services:
  minecraft:
    image: itzg/minecraft-server:latest
    container_name: mc-server
    ports:
      - "25565:25565"
    environment:
      EULA: "TRUE"
      TYPE: "PAPER"
      VERSION: "LATEST"
      MEMORY: "4G"
      TZ: "Asia/Seoul"
    volumes:
      - /volume1/docker/minecraft/data:/data
    restart: unless-stopped

핵심은 4개야. EULA=TRUE, 포트 25565 매핑, /data 볼륨, 메모리 제한.

Step 3. DSM 방화벽/보안 설정

여기 꼭 해줘야 해. 열어야 할 건 최소한만 열고, 관리자 계정은 비활성화 또는 이름 변경 권장.

  • DSM 방화벽에서 Minecraft TCP 25565 허용
  • DSM 관리 포트(5000/5001)는 외부 공개 금지
  • 2단계 인증(2FA) 활성화
  • 자동 차단(로그인 실패 횟수 제한) 활성화

Step 4. 공유기 포트포워딩 설정

공유기 관리자 페이지에 접속해서 포트포워딩을 추가해.

  • 외부 포트: 25565
  • 내부 IP: NAS 고정 IP (예: 192.168.0.20)
  • 내부 포트: 25565
  • 프로토콜: TCP (일부 공유기는 TCP/UDP 같이 열어도 됨)

그리고 NAS 내부 IP는 DHCP 예약으로 고정해. 이거 안 하면 어느 날 IP가 바뀌고 서버가 갑자기 안 열릴 수 있어.

Step 5. 외부 접속 테스트

같은 와이파이 말고 LTE/5G에서 테스트해야 정확해. 접속 주소는 공인IP:25565 또는 DDNS를 쓴다면 도메인:25565로 접속.

친구에게 접속 시도 부탁해서 플레이어 입장 로그까지 확인하면 완료!

내가 겪었던 실패 경험 (진짜 자주 터지는 것들)

실패 1: 포트는 열었는데 접속 불가
원인: NAS IP가 바뀜. 해결: DHCP 예약으로 NAS IP 고정.

실패 2: 서버는 켜지는데 렉 심함
원인: 메모리 부족 + 월드 청크 과다. 해결: MEMORY 4G 이상, 뷰 디스턴스 조정, 불필요 플러그인 정리.

실패 3: 업데이트 후 월드 깨짐
원인: 백업 없이 버전 변경. 해결: 업데이트 전 /data 폴더 스냅샷/백업 후 진행.

운영할 때 꼭 지켜야 할 주의점

  • 보안: DSM 관리자 포트 외부 노출 금지, 마크 포트만 개방
  • 메모리: 2~3명은 2G도 가능하지만, 4명 이상이면 4G 이상 권장
  • 백업: 최소 주 1회 월드 자동 백업 + 업데이트 전 수동 백업
  • 재시작: 매일 새벽 자동 재시작 걸어두면 장시간 운영 안정성에 도움

마무리

요약하면, DSM 7.0에서 Docker로 여는 건 생각보다 어렵지 않아. 핵심은 포트포워딩 정확히, NAS IP 고정, 그리고 백업 습관이야. 이 3개만 지켜도 스트레스가 확 줄어.

설정하다가 막히는 구간(공유기 모델별 화면, DDNS, 플러그인 추천)이 있으면 댓글로 남겨줘. 쓰는 NAS 모델/공유기 모델 같이 적어주면 내가 최대한 맞춰서 답변해볼게!

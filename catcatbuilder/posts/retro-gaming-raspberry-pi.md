## 라즈베리파이로 거실 TV에 레트로 게임기 만들기 (완벽 가이드)

**왜 이 글을 읽어야 할까요?**

추억의 오락실 게임을 거실 TV로 불러오고 싶으신가요? 라즈베리파이 하나면 3만원대로 1000개 이상의 클래식 게임을 즐길 수 있습니다. 2020년에 제가 직접 만들어서 3년째 잘 쓰고 있는 방법을 모두 공개합니다.

---

### 1. 준비물 (총 4~5만원 예상)

**필수품:**
1. **라즈베리파이 4 (2GB 이상)** - 3만원대
   - 3B+도 가능하지만 4 추천 (성능 차이 큼)
2. **Micro SD 카드 32GB 이상** - 5천원대
   - 게임 ROM 많이 넣을 거면 64GB+
3. **HDMI 케이블** - 집에 있는 거 사용
4. **USB 전원 어댑터 (5V 3A)** - 5천원대
   - 안드로이드 충전기 2.5A 이상이면 대체 가능
5. **USB 게임 패드** - 4~8천원대
   - 알리익스프레스에서 "USB SNES controller" 검색

**선택품:**
- 방열판 or 케이스 (3천원대)
- 조이스틱 완제품 (3~4만원대) - 패드 대신

---

### 2. 소프트웨어 설치 (30분 소요)

**Step 1: RetroPie 이미지 다운로드**
```
1. https://retropie.org.uk/ 접속
2. Download → Raspberry Pi 4 선택
3. .img.gz 파일 다운로드 (약 800MB)
```

**Step 2: SD 카드에 굽기**
```
# macOS
brew install balenaetcher
# BalenaEtcher 실행 → 이미지 선택 → SD 카드 선택 → Flash

# Windows
# Rufus 프로그램 사용 (공식 추천)
```

**Step 3: 첫 실행**
```
1. SD 카드를 라즈베리파이에 꽂기
2. HDMI로 TV 연결
3. 전원 연결 (USB-C)
4. 자동 부팅 후 RetroPie 로고 확인
```

---

### 3. 초기 설정 (15분)

**게임 패드 설정:**
- 첫 화면에서 버튼 매핑 시작
- A/B/X/Y, Start/Select, L/R, D-pad 순으로 누르기
- Hotkey는 "Select" 버튼 추천

**Wi-Fi 연결:**
```
RetroPie 메뉴 → Wi-Fi → SSID 선택 → 비밀번호 입력
```

**한글 설정 (선택):**
```
RetroPie 설정 → raspi-config → Localisation → KO 선택
```

---

### 4. 게임 넣기 (ROM 다운로드)

**⚠️ 저작권 주의:**
- 자신이 소장한 게임의 ROM만 사용하세요
- 또는 공개된 홈브류 게임 활용

**전송 방법 3가지:**

**방법 A: USB로 복사 (가장 쉬움)**
```
1. USB를 FAT32로 포맷
2. USB 루트에 retropie 폼더 생성
3. USB를 라즈베리파이에 꽂기 (30초 대기)
4. USB를 PC에 다시 꽂으면 roms 폼더 생성됨
5. 해당 콘솔 폼더에 .rom 파일 복사
6. 다시 라즈베리파이에 꽂기
```

**방법 B: SFTP로 전송 (Wi-Fi 필요)**
```
# IP 확인: RetroPie 메뉴 → Show IP
# 파일질라나 Cyberduck에서 접속
호스트: 라즈베리파이 IP
ID: pi
비밀번호: raspberry
경로: /home/pi/RetroPie/roms/
```

**방법 C: Samba 공유 (네트워크 드라이브)**
```
Windows 파일 탐색기 주소창에 입력:
\\\\라즈베리파이IP\
또는 \\\\retropie\
```

### 6. 자주 하는 실수 (내가 겪은 것들)

**❌ "TV에 연결했는데 화면이 안 나와요"**
→ HDMI 케이블이 라즈베리파이 4의 **Micro HDMI** 구멍에 꽂았는지 확인
(일반 HDMI 아님! 어댑터 필요할 수 있음)

**❌ "게임 패드가 인식이 안 돼요"**
→ 부팅할 때 패드를 꽂은 상태로 시작하세요
→ 또는 USB 허브 사용 (전력 부족일 수 있음)

**❌ "소리가 안 나와요"**
→ RetroPie 설정 → Audio → HDMI or Headphone 선택
→ TV 리모콘으로 음소거 해제 확인

**❌ "게임이 너무 끊겨요"**
→ 라즈베리파이 3을 쓰고 있다면 4로 업그레이드
→ 또는 overclocking 시도 (설정 → Advanced)

---

### 7. 업그레이드 팁

**조이스틱으로 업그레이드:**
- 알리익스프레스에서 "Arcade Joystick USB" 검색
- 2만원대 완제품 구매 후 USB 꽂으면 인식
- 가족/친구와 대전하기 좋음

**케이스 제작:**
- 아크릴 판 구매 후 자르기 (쇼핑몰에서 "아크릴 케이스" 검색)
- 3D 프린터가 있다면 Thingiverse에서 "RetroPi case" 검색

**OS 변경:**
- RetroPie 대신 RecalBox나 Lakka도 시도필 만함
- RecalBox는 설정이 더 쉬움 (한국어 지원)

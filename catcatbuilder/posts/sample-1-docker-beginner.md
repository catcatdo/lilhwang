## Docker가 뭔가요? 5분만에 이해하기

**왜 이 글을 읽어야 할까요?**

"Docker"라는 단어를 들어봤는데, 대체 뭔지 모르겠다면 이 글을 읽어보세요. 개발자 커뮤니티에서 자주 나오는 이 단어, 사실 엄청 쉬운 개념이에요.

---

### 1. Docker를 왜 쓸까?

여러분이 만든 앱을 친구한테 보여주고 싶다고 생각핸봐요.

"야 내가 만든 웹사이트 봐봐!"

그런데 친구 컴퓨터에서는 안 돌아가요. 왜냐고요? 여러분 컴퓨터에는 Python 3.9가 깔려있는데, 친구 컴퓨터에는 3.7이 깔려있거든요.

이런 상황에서 Docker는 **"내 컴퓨터에서 돌아갔으면 어디서든 돌아간다"**를 보장해줘요.

---

### 2. Docker의 핵심 개념

Docker는 **"컨테이너"**라는 것을 사용해요.

컨테이너는 뭐냐면... **이사할 때 쓰는 박스**라고 생각하면 돼요.

- 박스 안에 여러분 앱 + 필요한 모든 것들을 넣어요
- 이 박스를 친구한테 주면, 친구 컴퓨터에서도 똑같이 작동해요
- 박스 안 환경이 똑같으니까 어디서든 같은 결과가 나오는 거예요

---

### 3. 직접 따라하기: Hello Docker

**Step 1: Docker 설치**
```bash
# macOS
brew install --cask docker

# 또는 Docker Desktop 다운로드
# https://www.docker.com/products/docker-desktop
```

**Step 2: 터미널에서 실행**
```bash
docker run hello-world
```

이 명령어를 치면 Docker가 "Hello from Docker!"라고 인사해요. 설치 성공!

---

### 4. 자주 하는 실수

**❌ "Docker가 VM이랑 똑같은 거 아냐ー"**
→ 아니에요! VM은 컴퓨터 전체를 가상으로 만드는데, Docker는 훨씬 가벼워요.

**❌ "Docker는 꼭 써야 해?"**
→ 아니에요! 작은 프로젝트면 안 써도 돼요. 팀 프로젝트나 배포할 때 쓰면 좋아요.

---

### 5. 다음 단계

Docker를 조금 더 써보고 싶다면:

1. **Docker Hub** 가입하기 (묵료 이미지 저장소)
2. **Dockerfile** 작성핸보기 (내 앱을 박스에 담는 방법)
3. **docker-compose** 배우기 (여러 개 박스를 한꺼번에 관리)
